# 大浪恋爱工作台（workbench）

「恋爱之神大浪_PLUS」技能的本地可视化工作台：把微信多选复制的聊天记录导入网页，用**大浪云端向量库 + 中转站大模型**做分析（好感度六维 / 每句情绪意图 / 我方回复评级 / 下一句话术），并把女生档案库并入页面，分析时可直接建档、更新资料卡、绑定窗口。

> 本目录已**脱敏**：不含任何密钥（中转站 key / 向量库 license）、不含女生档案数据、不含本机绝对路径。换机器部署后**首次配置一次，之后永久免配**。

## 一、环境要求

- **Node ≥ 22.12**
- Python 3（仅「档案库」的写操作需要，跑 `profile_cli.py`，纯标准库、无需第三方包）
- 无需自装模型、向量库或任何 Python 依赖

> **Python 不在 PATH？** 在项目根建 `.env`，写入 `SYS_PYTHON=<你的 python 绝对路径>` 即可（本地向量库模式再额外配 `ST_ENV_PYTHON`）。

## 二、安装与启动（复制即用）

**最简单方式：双击 `start.bat`** —— 首次会自动 `npm install`，然后启动服务并自动打开浏览器 `http://127.0.0.1:5178`；之后每次双击，服务在跑就直接开页面。

手动方式：

```bash
cd workbench
npm install

# 开发模式（同时起后端 + 前端，浏览器开 http://127.0.0.1:5178）
npm run dev

# 或生产模式
npm run build
npm start        # 浏览器开 http://127.0.0.1:3178
```

> **下次 / 关闭后怎么打开**：双击 `start.bat`，或浏览器收藏 `http://127.0.0.1:5178`。服务窗口「dalang-workbench」关闭 = 服务停止，重开再双击 start.bat 即可。

> **Windows 小提示**：若你的目录是通过软链接 / junction（如 `C:\...\skills` 联接到别的盘）访问的，`npm run build` 可能报 `fileName ... must be strings` 绝对路径错误——改用**真实路径**（被联接指向的实际目录）运行即可，或直接用 `npm run dev`。

## 三、首次配置（只做一次，之后打开不用再填）

1. 打开页面 → 右上角「**模型设置**」。
2. **分析大脑（中转站）**：
   - Base URL 已**锁定官方中转站** `https://api.foundfutureai.cn/v1`，不可改、也无需改。
   - 还没有 Key？点设置弹窗里的「去中转站注册账号并创建 API Key ↗」，注册后创建 Key（推荐模型 **GPT-5.6-SOL**，注意填**小写** `gpt-5.6-sol`，渠道按模型名精确匹配、大小写敏感）。
   - 把 API Key 粘进「API Key」框。
3. **向量库（检索知识源）**：
   - 保持默认「**云端向量库（大浪服务器，用 key 调用）**」——情绪/意图标签 + 好感度判断依赖云端检索（规则/话术/案例/主策略），精度与「恋爱之神大浪」一致。
   - 把向量库 Key（license）粘进「向量库 Key」框。Key 由大浪云端管理页签发（获取方式见技能 SKILL.md §2）。
4. 点「**保存配置**」。

配置落在 `server/config.json`（已 gitignore，不上云、不提交）。也可用环境变量覆盖：`RELAY_API_KEY` / `RELAY_MODEL` / `EMBED_PROVIDER` / `EMBED_BASE_URL` / `EMBED_API_KEY` / `EMBED_MODEL`。

## 四、使用

1. **聊天分析**：微信里多选消息 → 复制 → 粘贴到页面。自动识别「我 / 对方」、增量去重对齐，分析每句情绪意图 + 我方回复评级 + 顶部好感度六维 + 「下一步」话术。
2. **档案库**：右侧「档案库」页看排名与详情；聊天页点右上角档案按钮，未绑定时选卡自动绑定并拉取历史聊天，没卡可一键新建并绑定。
3. **大浪指导**：底部「大浪指导」按钮，结合云端库 + 资料卡 + 当前聊天做推进对话（记录按窗口保存）。

## 五、脱敏说明（重要）

- 密钥（中转站 API Key、向量库 license）**只保存在你本机的 `server/config.json`**，本仓库不含、不上云、不入库。
- 女生档案库初始为空（`profile_db/data/` 只有空骨架），由你自己导入 / 建档，随用随长。
- 头像、聊天截图等个人素材不入库，由用户本地存放。

不是理论，不是书面知识，不是模型背书的通用建议。

### 1 · 排行榜看板 — 双击就开

档案库自带一张静态看板页，**双击打开，不需要服务器、不需要端口、不需要联网**。

- 首页按**兴趣度总分降序**排名，同分看最近更新时间
- 每张卡直接看到：结论（推进中 / 观察中 / 已止损）、真实度评级、六项分数拆解
- 在页面里改字段，退出输入框就自动存进本机浏览器，刷新还在
- 想放桌面：右键 `index.html` → 发送到 → 桌面快捷方式

### 2 · 女生档案库 — 一人一卡，越聊越准

| 项 | 内容 |
|:---|:---|
| 一人一卡 | 单独 JSON 文件，固定 19 个字段，禁止多人挤一张卡 |
| 兴趣度总分 | **100 分制**，由六项自动加总，禁止手填 |
| 互动时间线 | 每次聊天逐条追加，记录真实间隔（`47min` / `8h` / `25h`） |
| 原话原样 | 表情、分段、错别字都不改——它们本身就是判断依据 |
| 数据位置 | 存**你自己指定的目录**，技能包只放模板，升级重装都不会丢 |
| 安全兜底 | 删除前自动备份；写库走 CLI，内建查重、字段白名单、枚举校验 |

**兴趣度六项拆解（满分 100）**

| 分项 | 满分 | 判据 |
|:---|:--:|:---|
| 婚恋意愿强度 | 25 | 明确想结婚、近年婚育 = 满分 |
| 推进速度 | 20 | 明说尽快见面 = 满分；只想慢慢聊 = 低 |
| 响应质量 | 20 | 有反问 + 有延展 = 满分；闭合回复 = 0 |
| 展示面契合 | 15 | 与你的展示面钩子数量 |
| 真实度 | 10 | 认证齐全 + 逻辑自洽 = 满分 |
| 风险余量 | 10 | 越安全越高 |

### 3 · 资料解析 — 从截图里读出东西

发一张资料截图，它按 **5 个维度** 做真实性核验：

| 维度 | 看什么 |
|:---|:---|
| 经济逻辑 | 年薪百万 + 支教一年 = 逻辑断裂 |
| 职业痕迹 | 说做 AI，标签却全是看展喝茶 = 零技术痕迹 |
| 择偶标准 | 只谈精神契口、绝口不提硬件 = 刻意回避 |
| 完美人设 | 每个维度都是加分项、零平凡之处 = 可疑 |
| 时间线自洽 | 人设里最难圆的那一环，就是突破口 |

**配套三种测试手法**（用陈述句而不是问句，不暴露测试意图）：

- **假装共鸣**：「我之前也想过去支教，但工作没法停那么久」→ 看她是否自然延展
- **常识钩子**：「喀什昼夜温差应该挺大吧」→ 真实经历者接得住，编造的接不住
- **逻辑自洽**：「年薪百万去支教，公司怎么处理的？」→ 回避或两全 = 最不可信

> 判定标准很硬：钩子接住率 < 30%、或 6 个测试接住不到 3 个 → 直接给止损条件，不劝你继续投入。

### 4 · 平台识别 — 归属错了，全盘皆错

拿到截图先按**优先级**判断，而不是靠感觉：

1. **你的明确说明 > 一切视觉推断**（你说哪边是你，就以你说的为准）
2. 平台特征（绿色气泡 + 白底 = 微信；彩色背景对话框 = 探探 / 积目 / SOUL；信息流样式 = 小红书 / 抖音 / 微博）
3. 头像位置（右侧 = 你，左侧 = 对方，**有例外**）
4. 气泡颜色（最不可靠，仅作辅助）

再用**时间线合理性**兜底：出现两人同时发、时间倒流、一方连发十几条 → 归属大概率错了。
把你说的话当成对方的话，所有结论都会反向。**宁可多问一句，不猜错归属。**

### 5 · 公域 → 私域筛选 — 在公域别消耗

公域和私域是两套打法，混用就是白费力气：

| 阶段 | 只做这些 | 不做什么 |
|:---|:---|:---|
| **公域** | 验证真实性、回应能力、边界感、转私域意愿 | 不讨论深度关系，不在公域反复拉扯 |
| **私域** | 主动制造互动、拉伸情绪、建立暧昧、推进见面 | 不把筛选话术当主要输出 |

**开场按「有没有一对一对话通道」分流**（不是按平台名）：

- **已有通道**（双向匹配后 / 已加上好友）→ 只发 Hi，不先暴露底牌，看回复质量判兴趣
- **无通道且对方搭话量极大**（抖音私信、大 V 评论区）→ 一句话开场：先降维破夸赞免疫 → 再给非外貌的稀缺感 → 给个打招呼的理由 → 以退为进测兴趣

这两条**不能互换**：已匹配平台用长开场 = 先暴露底牌；高竞争冷启动裸发 Hi = 零存在感。

### 6 · 分析准确度 — 四道硬门挡住「感觉」

| 硬门 | 规则 |
|:---|:---|
| **云端检索门** | 不检索云端库就不许分析；正文引用 ≥3 条命中编号；命中全部 < 0.4 时必须明示「未命中强相关案例」；末尾展示 `result_id` |
| **证据分门别类** | 每条结论必须归入三类：① 截图能证明的事实 ② 你转述、仅供参考 ③ 仍未知。矛盾就指出矛盾，缺失就保持未知，**不为完整而虚构** |
| **置信度纪律** | 证据少于 2 项，置信度只能写「信息不足」，且不计入兴趣度总分 |
| **计划 ≠ 事实** | 判读对方反应**只以已经发出去的原文为准**。跟你讨论过的方案、上一轮准备好的话术、你口头说的「我打算约她」——一律不算已发生动作 |

再加两条流程护栏：

- **时间戳硬门**：同一句「嗯」，5 分钟回和 8 小时回是两件事。间隔未知时必须先问你，拿到前不对兴趣度下结论
- **任务分级**：收到消息先花 5 秒判级（快速下一句 / 单次分析 / 完整建档），小问题不跑完整流程

### 7 · 分析与指导回复 — 拆问题，也给下一句

**分析走五步链路**，不跳步、不提前下结论：

```
情绪落地 → 事实拆分 → 利益判断 → 明确建议 → 行动收束
```

**给回复时，一句话只准定一个目标**（禁止一句里又安慰、又调情、又邀约）：

| 策略 | 用它的信号 | 本轮只完成什么 |
|:---|:---|:---|
| 承接 | 她在倾诉、受挫、兴奋、分享 | 让她感到被听见 |
| 降压 | 她忙、累、冷、回避 | 停止追加，保留无压力窗口 |
| 调侃 | 她接梗、反问、斗嘴 | 加一点张力，再把球抛回去 |
| 轻推 | 对话顺畅但只在原地打转 | 往前推进一小步，不逼承诺 |
| 约见 | 有共同兴趣或已接住软邀约 | 把线上热度落到低压见面 |
| 澄清 | 信息矛盾、一个未知改变决策 | 只问清一个关键事实 |
| 收线 | 单边投入、反复取消、明确拒绝 | 停止无效供给 |

**落到文字上，还有三层打磨**：

- **拆条** — 单条 ≤ 10 字，超长拆成两条以上，像真人打字
- **口吻校准** — 长度 / 熟悉度 / 用词 / 媒介 / 关系结构五项对齐你平时的说话方式
- **三档方案** — 有真实权衡时给稳健 / 会撩 / 强势三版；强势是划边界和快速筛选，不是羞辱或控制

**风险识别与止损**也在这里：识别到捞女、拜金、资源索取、人设型苦情、多线并行时，直接点明风险并给出止损条件，不顺着情绪往前推。

## 常见问题

**档案存在哪？会不会上传？**
存在你第一次建档时指定的目录里，技能包内只有空模板。技能不上传、不收集任何数据。

**升级技能包会丢档案吗？**
不会。档案在技能包外，覆盖安装只动技能包本体；库根路径记在本机配置文件里，重装后自动认。

**页面打不开 / 需要起服务器吗？**
不需要。看板是纯静态页，双击 `index.html` 直接打开，没有端口、没有后端、不联网。

**能直接手改资料卡 JSON 吗？**
不建议。CLI 内建查重、字段白名单、枚举校验、分数上限和删除前自动备份，手改会绕过全部校验，页面可能读不出来。

**没有聊天记录能算兴趣度吗？**
不能。没有互动时间线时，响应质量分强制为 0，不允许凭资料想象打分。

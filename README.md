# 恋爱之神大浪 · Skills 本地版本

一套面向社交平台（探探 / 积目 / SOUL / 牵手 / 抖音 / 微博 / 小红书 / 微信）的**恋爱分析与推进计划**技能集。

核心思路：**云端是知识源，本地 Agent 是分析引擎**。

- 云端提供：规则库（103 条）+ 话术库（60 条）+ 实战案例库（101 个）+ 主策略库（15 条），并通过 Embedding 做语义检索
- 本地提供：用你自己的模型组织输出，支持用户资料建档与女生资料卡管理
- 用户无需安装模型、向量库或 Python 环境

## 能力范围

| 能力 | 说明 |
|:---|:---|
| 公开资料分析 | 基于截图、简介、照片、朋友圈、聊天记录解析对方情况 |
| 真实性核验 | 识别资料造假、人设型苦情、多线并行 |
| 风险识别 | 捞女 / 拜金 / 资源索取 / 三观不正 |
| 恋爱观解读 | 从公开信息反推对方的择偶逻辑 |
| 推进计划 | 输出升温 → 暧昧 → 邀约的完整节奏 |

## 快速开始

1. 把本目录整个放进你的技能目录，例如：
   - WorkBuddy / CodeBuddy：`~/.workbuddy/skills/恋爱之神大浪_PLUS/`
   - Codex / Claude：对应平台的 skills 目录
2. 用你的客户端加载该技能，触发词示例：
   - 「帮我分析这个女生」
   - 「她资料是真的吗」
   - 「怎么聊天升温」
   - 「怎么约出来」
   - 「这个平台怎么开场」
3. 首次使用需要一张许可证（license），通过 `scripts/cloud_client.js configure <许可证>` 写入本机配置后即可长期免配。

> 详细安装与配置步骤见 `恋爱之神大浪_PLUS安装与使用全攻略.docx` 与 `SKILL.md`。

## 运行环境

- Node.js（用于 `scripts/cloud_client.js`，无需 npm install）
- 任意支持读取本地文件的 AI 客户端（WorkBuddy / CodeBuddy / Codex / Claude 等）

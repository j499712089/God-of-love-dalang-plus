## 这是什么？能帮你做什么？

这不是一套「话术模板」，而是一套**判断系统**。它把十年实战经验沉淀成规则库、话术库、案例库放在云端，让 AI 在分析时**先查云端库、再给结论**。

| 层级 | 解决的问题 | 输出 |
| --- | --- | --- |
| **看人** | 她资料是真是假？值不值得投入？ | 五维真实性核验 + 风险识别 + 兴趣度评分 |
| **回话** | 这一句我该怎么接？ | 1–3 条候选话术 + 每条为什么这么接（默认 ≤10 字，像真人打字） |
| **推进** | 怎么从闲聊走到线下？ | 升温 → 暧昧 → 邀约的分阶段计划 |

装好之后你能获得：

- **女生资料核验** —— 判断资料真假，识别捞女 / 拜金女 / 三观不正 / 苦情人设 / 多线并行 / 资源索取

- **聊天升温** —— 逐句给「下一句怎么回」，真人感话术、超长自动拆条
- **邀约推进** —— 公域筛选 → 私域升温 → 线下邀约全链路计划

## 二、快速开始（装本地工作台）

### 路线 A：Windows 一键（推荐，一次装好永久免配）

1. 下载本仓库到任意目录，例如 `D:\恋爱之神大浪_PLUS`

   - 首次会自动 `npm install`（约 1–7 分钟，取决于网络），然后启动服务并自动打开浏览器

```bash
cd workbench
npm install

# 开发模式：同时起后端(3178) + 前端(5178)
npm run dev
# 浏览器打开 http://127.0.0.1:5178

# 或生产模式
npm run build
npm start
# 浏览器打开 http://127.0.0.1:3178
```

> `npm install` 没有输出不代表卡死，179 个包约 1–7 分钟。想加速：

> 「我拿到许可证了，帮我激活恋爱之神大浪_PLUS」

AI 会自动执行：

```
① 读取本机配置文件 ~/.dalang/config.json
② 发现没有许可证 → 向你索要 Key
③ 你提供 Key → 运行云端校验
④ 校验通过 → 自动写入配置文件（一次性，之后永不再问）
⑤ 校验失败 → 不写入，请你重新确认 Key
```

### 4.2 激活成功的标志

```
has_license: true          ← 许可证已就绪
has_library_root: true     ← 档案库位置已就绪（建档时配置）
云端额度：每小时 50 次检索
```

### 4.3 也可以手动配置（命令行）

```bash
# 写入许可证（只做一次）
```

配置与用户资料统一存放在 `%USERPROFILE%\.dalang\config.json`（macOS/Linux：`~/.dalang/config.json`）：

## 七、日常使用四步法

装好并激活后，按这四步完成「建档 → 分析 → 追踪 → 看板」的完整闭环。

### 7.1 第一步：建立你自己的用户档案

技能要求先建「用户档案」（你是谁、你的优势），后续分析才会结合你的情况给建议。对 AI 说：

> 「帮我建用户档案，我的信息：年龄 XX、职业 XX、城市 XX、我最大的优势是……」

AI 会问几个问题（平台、年龄、职业、展示面、恋爱目标等），照实回答即可。**你不想提供的信息可以不提供**，AI 会标记「未提供」，不会瞎编。

### 7.2 第二步：把女生资料丢给 AI

1. 把她的资料截图（探探 / 积目 / SOUL / 抖音 / 小红书 / 微信朋友圈等）发到对话
2. 对 AI 说：「**帮我分析这个女生**」
3. AI 会先问你是否建档：
   - **新建（推荐）**：生成资料卡进档案库，以后每次聊天都能增量更新、算兴趣度、进排行榜
   - **只看一次**：只当场分析，不落库

随后 AI 调用云端知识库，输出完整分析：

- 五维**真实性核验**
- 8 轮**危险信号扫描**
- 她的**恋爱观与兴趣度**
- 「**下一句怎么回**」（≤10 字一条，像真人打字）
- **升温 - 暧昧 - 邀约**推进计划
- **该不该止损**

### 7.3 第三步：持续追踪

聊完天，把聊天记录发给 AI，说「**更新 XX 的档案**」，AI 会：

- 追加互动时间线（原话、间隔时间）
- 重算兴趣度分数
- 调整推进计划

> 技能强调「**原话原样、时间真实**」，资料越完整，判断越准。

### 7.4 第四步：查看排行榜与档案库

所有建档的女生会进入你的「档案库看板」：

- 兴趣度排名
- 结论（推进中 / 观察中 / 已止损）
- 互动历史

对 AI 说「**打开我的档案库 / 发我看板**」，AI 会返回网页文件路径，双击即可打开，**不需要启动任何服务**。

## 八、档案库（女生资料卡）

每个女生一张 JSON 卡，包含 19 个字段（基础信息 / 兴趣度六项分解 / 每条推断的证据 - 假设 - 验证 / 互动时间线 / 结论）。

**统一走 CLI 写入，不要手写 JSON：**

```bash
cd profile_db

# 首次建库（库根只建一次）
python scripts/profile_cli.py init --path "D:\我的档案库"

# 新建档案卡
python scripts/profile_cli.py new --name "..." --platform "微信"

# 改字段 / 追加时间线
python scripts/profile_cli.py set <id> <字段> <值>
python scripts/profile_cli.py timeline <id> --date 2026-09-23 --text "..."

# 重建排名与网页数据
python scripts/build_db.py
```

字段规范见 `profile_db/SCHEMA.md`，完整教程见 `profile_db/档案管理教程.md`。

> 档案库默认写在**用户库根**（如 `D:\我的档案库`），**不会写进技能包**，所以升级 / 重装技能不会丢档案。

## 十一、你必须知道的几条规则

1. **没 Key 不分析** —— 没激活许可证，AI 不会凭自己印象瞎分析，它会停下来找你要 Key。这是设计，不是故障。
2. **分析必查云端** —— 每次分析前，AI 必须调用云端知识库再给结论，引用具体的规则 / 话术 / 案例编号。**如果分析里一个编号都没有，说明它没按规范执行，可要求重来。**
3. **Key 过期要续** —— 提示「无效 / 过期 / 被吊销」时，加微信 **DLang099** 处理。
4. **只分析你提供的信息** —— AI 不会去人肉搜索、跟踪对方；遇到明确拒绝、不舒服的信号，AI 会停止推进。
5. **档案库是你自己的** —— 资料存在你自己选的目录（默认 D 盘），升级 / 重装技能不会丢档案。

## 十二、常见问题（FAQ）

**Q：技能装在哪？**
一个叫 `恋爱之神大浪_PLUS` 的文件夹，放进客户端的技能目录。**是整个文件夹，不是单个文件。**

**Q：双击 bat / 桌面图标出现乱码？**
本仓库所有 `.bat` 都是 **GBK 编码 + CRLF 换行 + 首行 `chcp 936`**。乱码说明文件编码被改过（例如用编辑器另存为 UTF-8，或从旧版本拷贝）。修复：用 GBK 重新保存该 bat，或直接用 `npm run dev` 手动启动。

**Q：`npm install` 很慢 / 卡住没输出？**
正常，实测 179 个包约 1–7 分钟。想加速：`npm config set registry https://registry.npmmirror.com`

**Q：端口被占用（3178 / 5178）？**

```bash
netstat -ano | findstr ":3178"
taskkill /PID <PID> /F
```

**Q：提示找不到 Python？**
在 `workbench/` 目录建 `.env`，写入本机 Python 绝对路径：`SYS_PYTHON=C:\Path\To\python.exe`

**Q：Key 输错了怎么办？**
把正确 Key 重新发给 AI，说「重新配置许可证」，它会覆盖旧值。

**Q：每次用都要输 Key 吗？**
不用。Key 只配置一次，自动存在 `~/.dalang/config.json`，之后自动读取。

**Q：激活过一次还要激活吗？**
不用，Key 存在本机，自动读取。

**Q：换电脑 / 重装怎么迁移？**
拷走整个技能目录 + 你的用户库根（`library_root` 指向的目录），在新机器上重跑一次「快速开始」并重新配置 Key 即可。档案数据是明文 JSON，直接搬。

**Q：手机能用吗？**
能，见[第五章](#五手机与云端调用)（远程会话 / 传图给电脑 两种方式）。

**Q：网页看板打不开？**
双击 `profile_db/index.html` 即可，不需要起服务、不需要联网后端。

**Q：分析结果想重新生成？**
直接说「重新分析」，或补充更多资料后再问一次。

**Q：浏览器提示 `Blocked request. This host is not allowed.`？**
只在把 Vite 暴露到公网域名时出现。本项目默认只监听 `127.0.0.1`；如需公网访问，在 `vite.config.ts` 中配置 `server.allowedHosts`。

**Q：遇到任何问题找谁？**
微信 **DLang099**，一对一售后。

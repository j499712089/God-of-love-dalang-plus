## 这是什么？能帮你做什么？

这不是一套「话术模板」，而是一套**判断系统**。它把十年实战经验沉淀成规则库、话术库、案例库放在云端，让 AI 在分析时**先查云端库、再给结论**。

| 层级 | 解决的问题 | 输出 |
| --- | --- | --- |
| **看人** | 她资料是真是假？值不值得投入？ | 五维真实性核验 + 风险识别 + 兴趣度评分 |
| **回话** | 这一句我该怎么接？ | 1–3 条候选话术 + 每条为什么这么接（默认 ≤10 字，像真人打字） |
| **推进** | 怎么从闲聊走到线下？ | 升温 → 暧昧 → 邀约的分阶段计划 |

装好之后你能获得：

- **女生资料核验** —— 判断资料真假，识别捞女 / 拜金女 / 三观不正 / 苦情人设 / 多线并行 / 资源索取
- **恋爱观解读** —— 性格、需求、对你的真实兴趣度
- **聊天升温** —— 逐句给「下一句怎么回」，真人感话术、超长自动拆条
- **邀约推进** —— 公域筛选 → 私域升温 → 线下邀约全链路计划
- **资料卡建档** —— 每个女生一张档案卡，记互动时间线、打分、结论、进排行榜
- **持续追踪** —— 每次聊天记录丢进来，自动增量更新、重算分数

**整套系统怎么协作：**

```
你（AI 客户端：WorkBuddy / Codex / Cursor …）
        │  ① 安装技能包
        ▼
恋爱之神大浪_PLUS 技能
        │  ② 激活许可证（Key）
        │  ③ 分析前自动调用云端检索

官方云端知识库（103 规则 + 60 话术 + 101 实战案例 + 15 主策略，在线向量检索）
```

> **一句话总结：技能包 + 激活 Key + 喂资料 = AI 帮你做恋爱军师。**

| | 市面上的 AI 恋爱助手 | 本技能 |

### 库里都有哪些招式

不是名词解释，是能直接用的判断和话术：

| 招式 | 解决什么 |

| **Hi 测试法** | 已有对话通道时只发两个字，看回复质量判兴趣 |
| **高搭话量一句话开场** | 消息会被淹没的冷启动场景，一句话完成破夸赞免疫 + 稀缺感 + 测兴趣 |

完整条目在云端向量库：**103 条规则 · 60 条话术 · 101 个实战案例 · 15 条主策略**，全部由大浪本人校准。

## 二、快速开始（装本地工作台）

### 2.1 Windows 一键（推荐）

1. 下载本仓库到任意目录，例如 `D:\恋爱之神大浪_PLUS`
   > **整个文件夹一起放**，别只拷 `workbench` 子目录（技能包要整份）。
2. **双击 `workbench\start.bat`**

`start.bat` 会自动按顺序做这些事：

| 步骤 | 做什么 | 首次 | 以后 |
| --- | --- | :---: | :---: |
| ① | 查 `3178` 端口：服务已在跑 → 直接打开页面 | — | ✅ |
| ② | 探测 `node` / `npm` 是否在 PATH，缺了给中文报错并暂停 | ✅ | ✅ |
| ③ | 没有 `node_modules` → 自动 `npm install`（约 1–7 分钟） | ✅ | — |
| ④ | 后台启动服务（后端 3178 + 前端 5178），窗口标题 **`dalang-workbench`** | ✅ | ✅ |
| ⑤ | 自动打开浏览器 <http://127.0.0.1:5178> | ✅ | ✅ |

> `npm install` 期间**没有输出是正常的**（179 个包）。想加速：`npm config set registry https://registry.npmmirror.com`

### 2.2 桌面快捷方式怎么来（重点说明）

> ⚠️ **`start.bat` 本身不会往桌面放图标。** 想要桌面「大浪恋爱工作台」图标，有两条路，任选一条：

| 方式 | 操作 | 适合 |
| --- | --- | --- |
| **A · 让 AI 帮你建**（推荐） | 把本技能装进 WorkBuddy / Codex / Cursor 等客户端，说一句「**帮我装工作台**」。AI 会 `npm install` + 启动 + **亲手在桌面创建「大浪恋爱工作台」快捷方式**，最后把链接发给你 | 你装了 AI 客户端 |
| **B · 双击一个 bat 自己建** | 双击 `workbench\创建桌面快捷方式.bat`，桌面立刻出现「大浪恋爱工作台」图标（指向 `start.bat`） | 纯手动下载、没有客户端 |

建好之后：**双击桌面「大浪恋爱工作台」= 一键启动**，以后不用再进目录。

> 图标为什么是 shell 自带样式？快捷方式直接复用系统 `SHELL32.dll` 图标，不改系统任何设置。

### 2.3 手动启动（macOS / Linux / 想自己控制）

```bash
cd workbench
npm install

# 开发模式：同时起后端(3178) + 前端(5178)
npm run dev
# 浏览器打开 http://127.0.0.1:5178

# 或生产模式
npm run build
npm start
# 浏览器打开 http://127.0.0.1:3178
```

### 2.4 怎么关、下次怎么开

- 服务跑在标题为 **`dalang-workbench`** 的窗口里，**关掉它 = 停止服务**。
- 下次打开：双击桌面图标，或双击 `workbench\start.bat`，或浏览器打开收藏的 <http://127.0.0.1:5178>（服务没起时打不开）。

## 三、装进 AI 客户端（WorkBuddy / Codex / Cursor）

### 方式 A：从技能目录导入（推荐）

1. 打开 WorkBuddy 左侧栏的「技能 / Skills」入口

3. 重启客户端，技能即被识别

安装逻辑完全一致 —— **把技能文件夹放进客户端读取技能的目录，然后重启**。

新建对话，输入 `@恋爱之神大浪_PLUS`（或点技能图标选择它）。能看到技能介绍 = 安装成功。

## 六、工作台怎么用

顶栏两个页签：**聊天分析** / **档案库**。右侧常驻「**售后加微信 DLANG099**」按钮（点一下自动复制微信号）。
右上角随模式变化：**本地版**显示「模型设置」；**线上版**显示积分余额 + 退出登录。

### 6.1 聊天分析（主页面）

**三种喂聊天的方式：**

| 输入 | 怎么做 |
| --- | --- |
| **微信文字** | 微信里多选消息 → 复制 → 页面输入框 `Ctrl+V` |
| **平台截图** | 探探 / 积目 / SOUL / 抖音 / 小红书 / 微博 / 牵手 的聊天截图 → **直接粘贴**，自动转成对话再录入 |
| **图片占位** | 微信复制的记录里有「[图片] 文件名」时，把对应图片一起拖进来 → **按文件名对号入座**，贴到原位（图片本身在气泡里直接显示成缩略图） |

粘贴后程序自动判断「谁是我」，**只认不出才弹确认窗**：单说话人可一键「全是我说的 / 全是对方说的」，多人要求先整理格式。
> 微信语音复制不出来（剪贴板只带 `[语音]` 占位）—— 先在手机上长按语音「转文字」再复制。

**录入即自动分析**（v2.36 起，不分本地/线上）：导入、追加、改归属、删消息、换关系、绑资料卡之后**自动跑一轮**，不用手点。想重跑就用输入框上方的两个按钮：

| 按钮 | 干什么 |
| --- | --- |
| **分析好感度** | 单次总览：好感度分数 + 下一步动作 + 下一句话术 |
| **分析每条情绪** | 逐条**增量**：只分析新增消息，不重烧历史 |

**分析输出什么：**

- 每句的**情绪 / 意图**标签，我方回复**评级**（好 / 平 / 减分）
- 顶部**好感度六维**（意图 25 + 速度 20 + 回应 20 + 匹配 15 + 真实 10 + 风险 10 = 100）
- **「下一步」**：动作 + 可直接复制的话术（默认单条 ≤10 字，超长自动拆条，像真人打字）
- **公域开场白** 与 **私域下一步多轮**（含五步链路：情绪落地 → 事实拆分 → 利益判断 → 明确建议 → 行动收束）

### 6.2 大浪指导（底部按钮）

结合**云端知识库 + 她的资料卡 + 当前聊天**做推进问答，只给能照发的话术。
**必须已绑定资料卡且有聊天记录**才点得动（缺了会置灰，并把原因写在提示里）。对话记录按窗口保存。

### 6.3 一个窗口 = 一个女生 = 一张资料卡

左侧每个对话窗口**独立隔离**：聊天记录、绑定关系、分析结果互不串（换账号也不会串）。
新建窗口 → 贴聊天 → 会自动建档并绑定；也可以去「档案库」点一张卡绑定，她的历史聊天会并入本窗口。

### 6.4 两个容易混的按钮（都在输入框上方）

| 按钮 | 存的是什么 |
| --- | --- |
| **存档到资料卡**（小人图标） | 把**本窗口的聊天记录**（最近 30 条）写进她的资料卡互动时间线，结论写进摘要 |
| **更新资料**（证件图标） | 拖入她的**朋友圈 / 公域资料截图**，AI 读取后更新资料卡 —— 这是「存资料」，与上面「存聊天」是两件事 |

### 6.5 更新资料（截图建档）

选平台 → 拖入资料页 / 相册 / 动态截图（**张数不限**）→ AI 读出昵称 / 年龄 / 城市 / 职业 / 简介 / 兴趣标签 / 照片印象 / 疑点 → **逐项可改**（读不到的字段留空，不编造）→ 保存。

- 还会给出**深层分析**：逐张照片深读（类型 / 穿搭 / 场景 / 姿态）、穿搭心理、人设经营、真实性**五维核验**、≥3 条带证据与双视角的推断、待确认项 / 机会 / 风险

## 七、从零到第一次分析

**本地工作台（路线 ①）标准流程：**

1. **确认三组跑通** —— 右上角「模型设置」，GPT / Jev / 向量库 三组都显示 **✓ 已跑通**（见 §4.1）。

## 八、档案库（女生资料卡）

每个女生一张 JSON 卡，**19 个字段**（基础信息 / 兴趣度六项分解 / 每条推断的证据-假设-验证 / 互动时间线 / 结论）。

**存在哪，取决于你走哪条路线：**

| 路线 | 数据位置 |
| --- | --- |
| ① 本地工作台（单机） | `workbench\profile_db\data\profiles\*.json` —— **就在技能包里，全本机，不外传**（`.gitignore` 已排除，不会被提交） |
| ② 线上网页版 | 服务端按账号隔离，各看各的 |
| ③ 只在客户端里分析 | 用户库根：Windows 取**首个非系统盘** `\<盘符>:\我的档案库`，没有额外盘则回退 `%USERPROFILE%\我的档案库`；macOS/Linux 为 `~/.nvsheng/library` |

**工作台里直接点就行**（推荐）；要手工批处理，也可以走 CLI —— **统一用 CLI 写入，别手写 JSON**（CLI 内建查重、字段白名单、枚举校验、删除前自动备份）：

```bash
cd profile_db

# 首次建库（库根只建一次）
python scripts/profile_cli.py init --path "D:\我的档案库"

# 新建档案卡（id 必须是「拼音_平台」小写下划线，如 xiaoyu_wechat）
python scripts/profile_cli.py new --name "..." --platform "微信"

# 改字段 / 追加时间线
python scripts/profile_cli.py set <id> <字段> <值>
python scripts/profile_cli.py timeline <id> --date 2026-09-23 --text "..."

# 重建排名与网页数据
python scripts/build_db.py
```

字段规范见 `profile_db/SCHEMA.md`，完整教程见 `profile_db/档案管理教程.md`。

> 档案在**技能包之外**（或工作台的数据目录里），升级 / 重装技能不会丢档案。

## 十、隐私与数据安全

**路线 ①（本地工作台）：你的数据不出本机。**

- ✅ 三个 Key（GPT / Jev / 向量库 license）只存在本机 `workbench/server/config.json` 与 `%USERPROFILE%\.dalang\config.json`，**均已在 `.gitignore` 中**
- ✅ 女生档案、聊天记录、头像截图**全部存本机**，本仓库内只有空骨架
- ✅ 云端只做**许可证校验 + 向量检索**，不保存你的聊天内容和档案
- ✅ 你的资料默认**不落盘、不进云端案例库**；只有你明确授权并脱敏后才会被审核入库
- ✅ 聊天窗口 / 会话按**登录账号**隔离（同一浏览器换账号不会看到别人的数据）

**路线 ②（线上网页版）**：数据存在你账号下，服务端按账号隔离；Key 由服务端统一注入，你在页面上看不到也填不了。

**从本仓库同步 / 二次上传前建议自查：**

```bash
git status --ignored                             # 看有没有被忽略但仍在磁盘上的敏感文件
git ls-files | findstr /i "config.json .env"     # 应为空
```

## 十一、你必须知道的几条规则

1. **分析必查云端** —— 每次分析前必须先检索云端知识库再给结论，并引用具体的规则 / 话术 / 案例编号。**如果分析里一个编号都没有，说明它没按规范执行，可以要求重来。**
2. **没有许可证就不分析** —— 本地版没配 license、线上版没订阅向量库，程序会**停下来提示你补配**，而不是凭模型印象瞎编。这是设计，不是故障。
3. **Key 过期要续** —— 提示「无效 / 过期 / 被吊销」时，加微信 **DLang099** 换新证。
4. **录入就自动分析** —— 贴完聊天不用手点，会自动跑一轮；觉得费额度可以在自己的中转站账户里控制用量。
5. **只分析你提供的信息** —— 不会去人肉搜索、跟踪对方；遇到明确拒绝、不舒服的信号，会停止推进。
6. **档案是你自己的** —— 本地版存在 `workbench\profile_db\data`，升级 / 重装技能不丢；线上版在你账号下。
7. **夜间别劝睡**（技能内置纪律）—— 21:30–02:00 是全天最好的推进窗口，技能不会用「早点睡 / 晚安」帮你收线。

`start.bat` 不会自动建图标（见 §2.2）。两条路：① 让 AI 客户端帮你装，它会顺手建好；② 双击 `workbench\创建桌面快捷方式.bat`，图标立刻出现。

**Q：技能装在哪？**
一个叫 `恋爱之神大浪_PLUS` 的文件夹，放进客户端的技能目录。**是整个文件夹，不是单个文件。**

**Q：双击 bat / 桌面图标出现乱码？**
本仓库所有 `.bat` 都是 **GBK 编码 + CRLF 换行 + 首行 `chcp 936`**。乱码说明文件编码被改过（例如用编辑器另存成了 UTF-8，或从旧版本拷过来）。修复：用 GBK 重新保存该 bat，或直接用 `npm run dev` 手动启动。**别用编辑器直接改这些 bat。**

**Q：双击 `start.bat` 报「'npm' 不是内部或外部命令」？**
Node 装了但没加进 PATH。重装 Node 并勾选 **Add to PATH**，或手动把 Node 安装目录加入系统 PATH。

**Q：`npm install` 很慢 / 卡住没输出？**
正常，实测 179 个包约 1–7 分钟。想加速：`npm config set registry https://registry.npmmirror.com`

**Q：编辑框里只有「模型设置」没有「积分」？**
对，**本地单机版就是免注册、免积分、免订阅**（自己接中转站、花自己的 Key）。积分 / 订阅只出现在线上网页版。

**Q：为什么模型设置是三组？GPT 和 Jev 是同一把 Key 吗？**
**不是。** 两个模型同站、**不同分组、两把独立 Key**（见 §1.2）。三组都显示 **✓ 已跑通** 才算配置完成。

**Q：本地版白用吗？费用怎么算？**
本地版不收你任何订阅费 / 积分，但你自己的**中转站账户**会按 token 扣费 —— 也就是说钱花在中转站，不花在本地这台机器上。

**Q：线上版怎么收费？**
向量库 **¥6.6/月**（不消耗积分）+ 积分按量充值 **¥1 = 100 积分**；注册送 500 积分 + 3 天试用。见 §4.2。

**Q：录入就自动分析，会不会很费？**
逐条情绪与好感度六维走的是便宜的 Jev；只有「下一步动作 / 话术」走 GPT 一次。想重跑用「分析好感度」「分析每条情绪」按钮（逐条是**增量**，只算新增消息）。

**Q：资料 / 图片识别很慢或报「识别失败」？**
多图深层分析要经「视觉分批提取 + 向量检索 + 长文综合」，**5 张图 1–3 分钟属正常**，别中途关页面。报错文案会带 HTTP 状态码，截图发给售后更快定位。

**Q：云端检索配额很快就满？**
线上按小时限流（当前为 200 次/小时，以服务端为准）。新版已内置**同窗口共享检索缓存**：同一份聊天反复问只算 1 次，配额消耗已降到原来的 1/5~1/10。仍不够就分批分析。

**Q：提示找不到 Python？**
一般不需要 Python。真要装：装一个 Python 3.9+（勾选 Add to PATH）即可；或在工作台目录建 `.env`，写 `SYS_PYTHON=C:\Path\To\python.exe`。
> 报 `spawnSync python EBUSY` 是命中了 Microsoft Store 的 python 存根，新版会自动绕开；仍报就装个真 Python。

**Q：端口被占用（3178 / 5178）？**

```bash
netstat -ano | findstr ":3178"
taskkill /PID <PID> /F
```

**Q：换电脑 / 重装怎么迁移？**
**路线 ①**：拷走整个技能目录（含 `workbench\profile_db\data` 里的档案），到新机器重跑「快速开始」并重填三个 Key。
**路线 ②**：重新登录账号即可，档案和订阅都在账号下。

**Q：手机能用吗？**
本地版不行（只监听 127.0.0.1）。用线上网页版 <https://dalang.wenmingjianyuce.cn>，界面已做手机适配。见第五章。

**Q：`profile_db/index.html` 看板打不开？**
那个静态看板需要先跑 `python profile_db/scripts/build_db.py` 生成数据；**更推荐直接用工作台的「档案库」页**（不需要额外命令）。

**Q：浏览器提示 `Blocked request. This host is not allowed.`？**
只在把 Vite 暴露到公网域名时出现。本地默认只监听 `127.0.0.1`；如需公网访问，在 `vite.config.ts` 里配置 `server.allowedHosts`。

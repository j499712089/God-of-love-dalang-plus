# 展示面真实性核验指南

## 为什么需要真实性核验？

**社交平台的根本问题**：展示面可以精心包装，文字可以复制粘贴，"完美人设"可以设计出来。

**真实性优先于兴趣度**：
- 一个对你兴趣极高但人设是假的女生 = 浪费时间 + 情感损失
- 一个兴趣中等但真实的女生 = 可以继续发展
- **真实度 = 关系的地基，兴趣度 = 关系的高度**

---

## 核心原则

### 1. 完美人设 = 可疑信号

**什么是完美人设**：
- 每个维度都是加分项（学历/收入/职业/爱好/价值观）
- 没有明显缺陷或平凡之处
- 关键信息模糊但暗示高价值
- 高价值符号密集（年薪百万+支教+养宠物+文艺+主动送花）

**为什么可疑**：
- 真实的人是有缺陷的、有平凡之处的
- 如果她在有限的展示面里塞进了大量高价值符号，这不是巧合，是策略
- 社交平台上有大量"如何打造高价值展示面"的教程，"支教"就是最常用的符号之一

### 2. 用常识验证，不用感觉

**感觉可以被误导，常识不会**：
- 感觉："她主动送花，肯定对我有兴趣" ❌
- 常识："年薪百万的人怎么处理工作去支教一年？" ✅

**三种常识验证**：
1. **经济常识**：年薪百万 = 月入8-10万，放弃一年 = 损失100万+职业连续性+行业竞争力
2. **职业常识**：AI从业者通常会有技术标签、会聊行业、会吐槽工作，零痕迹 = 可疑
3. **生活常识**：38岁女性找对象，正常会关注经济实力，完全不提 = 刻意回避

### 3. 矛盾点 = 突破口

**真实的人，信息是自洽的**；**假的人，信息是冲突的**。

找到展示面中互相矛盾的点：
- 年薪百万 vs 支教一年（经济逻辑矛盾）
- AI职业 vs 零技术标签（职业痕迹矛盾）
- 38岁 + 不提物质 vs 强调自己年薪百万（择偶标准矛盾）
- 工作忙缺乏生活技能 vs 日常逛展看剧养宠物（时间分配矛盾）

**矛盾越多，真实度越低。**

---

## 五大验证维度

### 1. 经济逻辑验证（rule_062）

**核心问题**：高收入 + 长期低收入行为 = 逻辑断裂

**典型场景**：
- 年薪百万 + 支教一年
- 年薪百万 + gap year（间隔年）
- 年薪百万 + 创业零收入期
- 年薪百万 + 辞职考研/出国

**合理解释的唯一可能**：
1. **辞职去的**：承认放弃百万年薪，有清晰的动机（职业倦怠/转型/财务自由）
2. **短期而非长期**：支教3个月（可以请假），不是一年
3. **远程工作**：但那就不是"全职支教"，也不是"年薪百万"了
4. **自由职业/咨询**：但那就不是"年薪"（年薪是稳定雇佣关系的概念）

**如果她说"公司给我保留职位"**：
- ❌ 不合理：哪个公司给年薪百万的人保留一年职位？
- ❌ 逻辑冲突：公司愿意等她一年 = 她的价值极高，但她为什么要放弃？

**验证方法**：
- 陈述句套话："我之前也想过去支教，但工作没法停那么久"
- 观察她是否主动解释自己怎么处理工作的
- 如果她闭合回复（"嗯""是呀"）或回避（"不想聊工作"），真实度极低

### 2. 职业痕迹验证（rule_063）

**核心问题**：声称从事某职业，但零相关痕迹 = 职业真实性存疑

**职业痕迹的表现**：
- **标签/兴趣**：技术人会有技术标签，律师会有法律标签，医生会有医学标签
- **吐槽**：真正从事某职业的人，会吐槽工作（"最近项目赶得要死"）
- **术语**：会自然使用行业术语（AI从业者会说"模型""训练""部署"）
- **圈子**：会聊行业八卦、同事、公司文化

**典型案例**：
- 她说自己是"AI从业者"，但所有标签都是"博物馆、看展、喝茶、舞台剧"
- 零技术标签、零行业吐槽、零专业内容
- **可能性**：①她是边缘岗位（产品/运营/市场，而非算法/工程师）；②职业是包装的；③刻意隐藏

**验证方法**：
- 陈述句测试："应该是大厂算法岗吧，最近应该挺忙的"
- 观察她是否能接住：真的会说具体公司/岗位/工作内容，假的会含糊应对
- 常识钩子："AI这行现在是不是都在卷大模型"
- 看她能否自然延展，还是闭合回复

### 3. 择偶标准审查（rule_064）

**核心问题**：38岁+ 不提房车/经济条件，只强调精神层面 = 可疑

**为什么可疑**：
- 年龄越大，择偶越现实，这是社会规律
- 38岁女性如果真的只要精神契合，她早就找到了（精神契合的门槛比物质门槛低）
- 她还单身 + 只谈精神 = 可能是她的真实条件达不到预期，用"不看重物质"降低被筛选风险

**两种可能**：
1. **真的不在乎物质**：但那她为什么强调自己年薪百万？（自相矛盾）
2. **用高价值人设筛选**：先用"支教/理想主义"吸引人，再测试对方经济实力

**验证方法**：
- 观察她是否会间接打听用户的职业/收入/房车
- 看她的择偶条款是否全是关系需求类（陪伴/理解/成熟）而零硬件要求
- 如果后续她开始问"你做什么的""你在XX住吗"，说明她确实在意物质

### 4. 完美人设警觉（rule_065）

**核心问题**：信息过载 + 过于完美 = 精心包装

**完美人设的特征**：
| 维度 | 她的展示 | 正常人的展示 |
|------|----------|--------------|
| 学历 | 985（华中科大） | 可能是普通本科 |
| 职业 | AI（高大上） | 可能是普通职员 |
| 收入 | 年薪100万+ | 可能是30-50万 |
| 价值观 | 支教（高价值符号） | 可能没有这种经历 |
| 爱好 | 文艺（博物馆/看展） | 可能是刷剧/逛街 |
| 宠物 | 边牧（高智商犬种） | 可能不养宠物 |
| 主动性 | 主动送花 | 可能等男生主动 |

**每个维度都是加分项 = 太完美了 = 可疑**

**真实的人**：
- 有优点也有缺点
- 有高光时刻也有平凡日常
- 有专业能力也有不擅长的领域
- **信息是有冲突的、有平凡之处的**

**验证方法**：
- 用常识性成本、职业连续性、时间线自洽性交叉验证
- 任何一个维度出现矛盾，整个人设可信度大幅下降
- 不要被单一高价值符号吸引，看整体逻辑是否自洽

### 5. 逻辑自洽性测试（rule_068）

**核心问题**：人设链条中最薄弱的一环 = 突破口

**最难圆的问题**："年薪百万的人怎么处理工作去支教一年？"

**四种可能的解释**：
1. **辞职去的**：为什么放弃百万年薪？（需要清晰动机）
2. **公司给长假**：哪个公司给百万年薪的人保留一年职位？（不合理）
3. **远程工作**：那就不是全职支教，也不是年薪百万了（逻辑冲突）
4. **自由职业**：那就不是"年薪"了（概念错误）

**这四条解释互相冲突且都不合理**

**真实 vs 假的反应**：
| 类型 | 反应 |
|------|------|
| 真实 | 坦诚代价："辞职了，想换个环境，回来再找工作" |
| 假的 | 试图两全："公司支持我""可以远程工作""还没最终定" |
| 回避 | "不想聊工作""到时候再说""先不想那么多" |

**两全 = 最不可信**

## 三种测试方法

### 方法1：陈述句套话（rule_066）

**核心原则**：用陈述句而不是问句，不暴露测试意图

**为什么有效**：
- 问句让对方知道你在测试，她会准备话术
- 陈述句伪装成分享或共鸣，她会下意识真实回应

**三种陈述句**：

#### 1. 假装共鸣
```
❌ 问句："你什么时候去支教的？"（暴露测试）
✅ 陈述句："我之前也想过去支教，但工作没法停那么久"
```

**观察**：
- 真实的人会自然延展："对 我也纠结了很久 最后还是辞职了"
- 假的人会闭合回复："嗯 有机会可以试试"

#### 2. 制造假设
```
❌ 问句："你9月几号回来？"（直接核实）
✅ 陈述句："你9月回来应该赶得上XX展"
```

**观察**：
- 真实的人会纠正你的假设："我10月才回 可能赶不上"
- 假的人会顺着你说："嗯 应该可以"

#### 3. 常识钩子
```
❌ 问句："喀什天气怎么样？"（太直接）
✅ 陈述句："喀什昼夜温差应该挺大吧 刚去不适应"
```

**观察**：
- 真实的人能接住："对 白天30度晚上10几度 刚来确实不太习惯"
- 假的人接不住："嗯""还好吧""习惯了"

### 方法2：常识钩子验证（rule_067）

**核心原则**：用常识性细节测试，真实经历者能接住，编造者接不住

**三类常识钩子**：

#### 1. 地理常识
针对"喀什支教"：
- "喀什昼夜温差挺大吧"
- "那边网络怎么样 能正常上网吗"
- "海拔高吗 会不会有高原反应"

**真实 vs 假的**：
| 钩子 | 真实回应 | 假的回应 |
|------|----------|----------|
| 昼夜温差 | "对 白天30度晚上10几度 刚来不适应" | "嗯""还好吧" |
| 网络状况 | "网络不太稳定 微信视频经常卡" | "还行""能上" |
| 高原反应 | "喀什海拔1300多 没啥反应" | "嗯""还好" |

#### 2. 职业常识
针对"AI职业"：
- "最近是不是都在卷大模型"
- "你们公司用的是什么框架"
- "AI这行加班应该挺多的吧"

**真实 vs 假的**：
| 钩子 | 真实回应 | 假的回应 |
|------|----------|----------|
| 大模型 | "对 我们组最近在做XX方向" | "嗯""是的" |
| 技术栈 | "我们用PyTorch""我不做算法 做产品的" | "不太懂""挺多的" |
| 加班 | "项目紧的时候确实很累" | "还好""看情况" |

#### 3. 生活常识
针对"养边牧"：
- "边牧精力旺盛 你去支教了狗怎么办"
- "边牧需要大量运动 每天遛多久"

**真实 vs 假的**：
| 钩子 | 真实回应 | 假的回应 |
|------|----------|----------|
| 支教期间 | "我妈每天给我发视频 它刚开始不适应" | "在家里""托给家人了" |
| 遛狗时间 | "早晚各一次 每次至少半小时 不然拆家" | "有时间就遛" |

**埋多个钩子，观察接住率**：
- 接住 80%+ = 真实度高
- 接住 50% = 真实度中等
- 接住 < 30% = 真实度极低

### 方法3：逻辑自洽性测试（rule_068）

**核心原则**：找到人设中最难圆的一环，直接测试

**最难圆的问题**：工作与收入的处理方式

**测试话术**：
```
"年薪百万去支教一年，公司怎么处理的？"
```

**四种可能的回答**：

#### 1. 辞职去的（✅ 可能真实）
```
她："辞职了，想换个环境，回来再找工作"
你：观察她是否有清晰的动机和规划
```

**追问**：
- "为什么突然想去支教"（看动机是否合理）
- "回来打算做什么"（看是否有规划）

#### 2. 公司给长假（❌ 不合理）
```
她："公司支持我，给我保留职位"
你：质疑："哪个公司这么好？"
```

**逻辑漏洞**：
- 年薪百万 = 核心员工，公司不可能等一年
- 如果公司愿意等 = 她的价值极高，她为什么要走？
- **自相矛盾**

#### 3. 远程工作（❌ 逻辑冲突）
```
她："可以远程工作"
你：质疑："那还是全职支教吗？"
```

**逻辑漏洞**：
- 远程工作 = 还在工作，不是"支教一年"
- 年薪百万的工作能远程 = 不需要天天在公司，那为什么要"去支教"？
- **概念混淆**

#### 4. 自由职业/咨询（❌ 概念错误）
```
她："我是自由职业，时间比较灵活"
你：质疑："那不是'年薪'吧？"
```

**逻辑漏洞**：
- "年薪"是稳定雇佣关系的概念，自由职业不叫"年薪"
- 自由职业说"年收入"，不说"年薪"
- **偷换概念**

#### 5. 回避/模糊（❌ 最可疑）
```
她："不想聊工作""到时候再说""还没最终定"
```

**回避 = 无法自圆其说 = 假的**

## 实战案例：38岁女生支教人设

### 展示面信息

| 维度 | 数据 | 分析 |
|------|------|------|
| 年龄 | 38岁 | 择偶焦虑期，正常会关注经济实力 |
| 学历 | 华中科大·本科 | 985，加分项 |
| 职业 | AI | 模糊，不说具体岗位 |
| 收入 | 年薪100万+ | 自填，无法验证 |
| 行为 | 9月去喀什支教 | 与年薪百万冲突 |
| 标签 | 博物馆/看展/美术馆 | 零技术痕迹 |
| 择偶 | 先认真谈场恋爱 | 不提房车/经济条件 |
| 主动性 | 主动送花 | 正向信号 |

### 五大矛盾点

1. **经济逻辑矛盾**：年薪100万 + 支教一年
2. **职业痕迹矛盾**：AI职业 + 零技术标签
3. **择偶标准矛盾**：38岁 + 不提物质 + 强调自己年薪百万
4. **时间分配矛盾**：工作忙缺乏生活技能 + 日常逛展看剧养宠物
5. **信息密度矛盾**：所有维度都是加分项，零缺陷

### 真实度评估

**初步判断**：真实度 < 30%

**理由**：
- 5个矛盾点，4个无法自洽
- 关键信息全部模糊（AI职业不说公司，支教时间线不清，工作处理方式不明）
- 完美人设，零平凡之处
- **高概率是精心包装的展示面**

### 验证策略

#### 第1-2轮：陈述句套话

```
推荐话术：
"我之前也想过去支教，但工作实在没法停那么久  
你9月去喀什，公司怎么处理的？"
```

**观察点**：
- 她是否主动解释工作处理方式？
- 她的解释是否合理？（辞职/长假/远程/自由职业）
- 她是否回避这个问题？

#### 第3-4轮：常识钩子

```
推荐话术：
"喀什昼夜温差应该挺大吧  
边牧怎么安排的？那狗精力太旺盛了"
```

**观察点**：
- 她能接住几个常识钩子？
- 她的回复有细节还是只有模板？
- 她是否闭合回复？

#### 第5-6轮：职业真实性

```
推荐话术：
"AI这行最近应该很卷吧  
你们是做算法还是产品？"
```

**观察点**：
- 她能否自然延展职业话题？
- 她是否暴露职业细节？
- 她是否转移话题？

#### 第7-8轮：止损决策

**如果6个测试中接住 < 3个**：
- 真实度极低
- 立即止损，不再投入

**如果接住 3-4个**：
- 真实度中等
- 继续观察，但保持警惕

**如果接住 5个以上**：
- 真实度较高
- 可以继续推进

## 总结

### 核心原则

1. **真实度优先于兴趣度**
2. **测试优先于推进**
3. **止损优先于挽救**
4. **常识优先于感觉**

### 三句话记住

1. **完美人设 = 可疑信号**
2. **矛盾点 = 突破口**
3. **真实的人能接住常识钩子，假的人接不住**

### 什么时候止损？

**出现以下2个以上信号，立即止损**：
- ✗ 关键信息全部模糊
- ✗ 陈述句套话，闭合回复
- ✗ 常识钩子，接住率 < 30%
- ✗ 逻辑自洽测试，回避或自相矛盾
- ✗ 展示面5个以上矛盾点

**止损动作**：
- 不争论、不质疑、不揭穿
- 直接降低投入，停止推进
- 把精力转向其他对象

# 平台识别与消息归属核对指南

> 通用方法论版（去除具体用户案例）。用于任何社交平台截图/资料分析的平台识别与消息归属判断。

## 一、消息归属判断优先级（从高到低）

1. **用户的明确说明 > 一切视觉推断**
   - 用户说"红色框是我/带头像的是我"，就以用户说明为准，不看颜色、位置、平台惯例
   - 拿到截图先问清楚："这是什么平台？哪边是你发的？有没有标注？"

2. **平台特征识别**
   - 绿色气泡 + 白色背景 → 微信
   - 彩色背景 + 对话框 → 探探/积目/SOUL 等交友平台
   - 白色背景 + 简洁界面 → 牵手/陌陌（需向用户确认）
   - 信息流/评论样式 → 小红书/抖音/微博/朋友圈

3. **头像位置（辅助验证）**
   - 通用规则：右侧 = 用户（自己），左侧 = 对方
   - 例外：部分平台不遵循此规则
   - **与用户说明冲突时，以用户说明为准**

4. **气泡颜色（最不可靠，仅辅助）**
   - 不同平台颜色规则不同
   - 单独依靠颜色判断风险极高

## 二、时间线合理性验证

消息归属错误的最快发现方法：

- 合理：用户发 → 对方回 → 用户再发（有来回节奏）
- 不合理：两人同时发、时间倒流、一方连续自言自语十几条 → 归属可能错了

**归因错误会导致全盘皆错**：把用户的话当成对方的话，所有分析都会反向。一旦发现错误，必须撤销所有基于错误归属的结论并重新分析。

## 三、每次分析前必过清单

- [ ] 用户有没有明确说"XX是我"？
- [ ] 我识别的平台是什么？依据充分吗？
- [ ] 哪些是用户的消息？依据是什么？
- [ ] 哪些是对方的消息？依据是什么？
- [ ] 时间线是否合理？
- [ ] 如果有红色框/标注，代表什么？问清楚了吗？
- [ ] 我的归属判断与用户说明是否一致？

**记住：宁可多问一句，不要猜错归属。归属错了，全盘皆错。**

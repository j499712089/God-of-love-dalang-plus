# 女生档案库（模板）

下载技能后**开箱可用**，无需配置、无需起服务器、不含任何他人数据。

---

## 一、怎么打开这个网页

**由 Agent 首次建库后提供** `<库根>/index.html`；这是用户库中的静态看板骨架，直接双击即可打开，不需要服务器、端口或网络。

页面首次读取同目录 `data/db.js`。用户在页面编辑字段，退出输入框即自动保存到本机浏览器 `localStorage`，立即回填；关闭或刷新页面后修改仍保留，不需要再次让 Agent 操作。Agent/CLI 后续重建源文件时，以用户库 JSON 为准，并可用页面“恢复原值”清除本机覆盖。

> 想放到桌面：右键 `index.html` → 发送到 → 桌面快捷方式。以后从桌面点开即可。

---

## 二、第一次打开会看到什么

档案库是空的，页面会显示引导卡片，告诉你两种建档方式：

**方式一（推荐）· 让 AI 建**

把女生的资料截图或简介发给 AI，说：

> 用恋爱之神大浪_PLUS 分析这个女生

AI 会先问你要不要建档。答「建档」，它就会：

1. 在 `data/profiles/` 写一张资料卡（一人一个 JSON）
2. 跑五维真实性核验（经济逻辑／职业痕迹／择偶标准／完美人设／时间线自洽）
3. 按六项算兴趣度总分并排名
4. 输出升温 → 暧昧 → 邀约的分阶段计划

刷新网页就能看到这张卡。

**方式二 · 自己建**

点页面上的「＋ 新增档案」，填昵称和平台先占位，之后再补内容。

## 三、后续每次聊天怎么记录

把新的聊天记录（截图或直接粘贴）发给 AI，说「她回了这些」。

AI 会追加到这个女生的**互动时间线**，并重算响应质量分、必要时改判结论（推进中／观察中／已止损）、更新后续话术计划。

记录时会保留你的原话原样——表情、分段、错别字都不改，因为这些本身就是判断依据。

> ⚠️ 时间戳很重要。同一句「嗯」，5 分钟回和 8 小时回是两件完全不同的事。发记录时尽量带上时间。

## 四、目录里都是什么

```
profile_db/
├── index.html          ← 双击这个打开网页
├── README.md           ← 本文件
├── SCHEMA.md           ← 资料卡字段规范（AI 写卡前会读）
├── assets/             ← 页面样式和逻辑
├── data/
│   ├── profiles/       ← 你的资料卡都在这（初始为空）
│   ├── db.js           ← 自动生成，别手改
│   ├── index.json      ← 自动生成，别手改
│   └── _backup/        ← 删除档案时自动备份到这
└── scripts/
    ├── profile_cli.py  ← 资料卡增删改查、校验与自动写入
    └── build_db.py     ← 重建排名与页面数据
```

## 五、想自己敲命令（可选）

日常交给 AI 就行。想手动操作的话：

```bash
python scripts/profile_cli.py list
```

其余命令看 `SCHEMA.md`，或直接问 AI。

**注意**：不要手写或手改 `data/profiles/*.json`。CLI 内建了查重、字段白名单、枚举校验、分数上限和自动备份，手改会绕过全部校验，页面可能读不出来。

## 六、数据在哪

**在你自己指定的目录里，不在技能包内。** 技能不上传、不收集任何数据。

第一次建档时 AI 会问你「档案库要存在哪」，你给个目录（比如 `D:\我的档案库`），它执行一次：

```bash
python scripts/profile_cli.py init --path "D:\我的档案库"
```

这会在该目录建好 `data/profiles/`、复制网页，并把绝对路径写入统一配置 `~/.dalang/config.json` 与该库根的 `library.json`。以后所有增删改查都自动认这个目录。

忘了存在哪，随时查：

```bash
python scripts/profile_cli.py where
```

想备份就整个库目录复制走；想清空就删掉 `data/profiles/` 里的 JSON，再跑一次 `python scripts/build_db.py`。

### ✅ 更新技能包不会丢档案

档案在包外，覆盖安装只动技能包；库根由 `~/.dalang/config.json` 的 `library_root` 记录，`data/` 原样保留。重装后无需重指；若配置文件丢失，再执行一次：

```bash
python scripts/profile_cli.py init --path "D:\我的档案库" --force
```

### 想换存放位置

先手动把整个库目录复制到新位置，再重指：

```bash
python scripts/profile_cli.py init --path "E:\新位置" --force
```
